    Configuratiebestanden verkrijgen van WireGuard-serviceproviders¶

    AzireVPN

    AzireVPN¶

    Officiële website

    1. Ga naar de officiële website van AzireVPN, meld je aan en open vervolgens de WireGuard Configuration generator.

    2. Selecteer bij de IP-optie IPv4. Klik vervolgens op Download Configuration.

    3. Volg daarna deze handleiding om door te gaan.

    4. Je kunt AzireVPN ook met de mobiele app instellen.

    Hide.me VPN

    Hide.me VPN¶

    Officiële website

    Hide.me VPN biedt een eenvoudige manier om de WireGuard-service op een GL.iNet-router te gebruiken.

    1. Maak via SSH verbinding met de router.

    2. Kopieer de onderstaande installatie-URL, plak deze in de terminal en druk op Enter. Met de rechtermuisknop plak je de tekst.

      curl -fsSL https://raw.githubusercontent.com/eventure/hide.client.routers/master/glinet_v4/hidemevpn | sh -s install

    3. De installatie wordt gestart en vervolgens wordt om je gebruikersnaam en wachtwoord gevraagd. Tijdens het typen of plakken van het wachtwoord verschijnt er niets in de terminal. Druk na het invoeren op Enter.

    4. Ga na voltooiing naar het webbeheerpaneel. Er is een hide.me VPN-groep gemaakt met configuratiebestanden. Maak op dezelfde manier verbinding als met elk ander configuratiebestand.

    Opmerking: de sleutel in het Hide.me VPN-configuratiebestand wordt vóór elke verbinding opnieuw gegenereerd en wordt na het verbreken van de verbinding ongeldig. Als je dit configuratiebestand naar andere apparaten kopieert, kunnen deze daarom geen verbinding maken.

    Referentie: hide.me VPN for Routers - GitHub

    Mullvad

    Mullvad¶

    Officiële website

    1. Ga naar de officiële website van Mullvad, meld je aan en open vervolgens de generator voor WireGuard-configuratiebestanden.

    2. Volg daarna deze handleiding om door te gaan.

    3. Je kunt Mullvad ook met de mobiele app instellen.

    PIA (Private Internet Access)

    PIA (Private Internet Access)¶

    Officiële website

    Je kunt de WireGuard-configuraties niet via de website downloaden. Gebruik de mobiele app om PIA VPN in te stellen.

    Surfshark

    Surfshark¶

    Officiële website

    1. Als je Surfshark gebruikt, meld je je aan en ga je naar deze pagina. Klik op Router en selecteer WireGuard.

    2. Selecteer in het volgende venster I don't have a key pair.

    3. Selecteer Generate a new key pair.

    4. Selecteer Choose a location nadat de sleutel is gegenereerd.

    5. Kies de locatie die je wilt instellen en klik naast de locatie op download. Je kunt de configuratiebestanden vervolgens downloaden.

    6. Volg daarna deze handleiding om door te gaan.

    AirVPN

    AirVPN¶

    Officiële website

    1. Als je AirVPN gebruikt, meld je je aan bij de website. Ga naar de Client Area en klik op Config Generator.

    2. Selecteer op de pagina Config Generator WireGuard in het gedeelte Protocols.

    3. Selecteer een server, scrol naar het einde en klik op Generate. Het configuratiebestand wordt gedownload.

    4. Volg daarna deze handleiding om door te gaan.

    Astrill

    Astrill¶

    Officiële website

    Als je Astrill gebruikt, meld je je aan en open je deze pagina om WireGuard-configuraties te genereren.

    Volg daarna deze handleiding om door te gaan.

    Windows, macOS, Linux

    Volg daarna deze handleiding om door te gaan.

    Volg de handleiding hier om de configuratie te maken.

    Volg daarna deze handleiding om door te gaan.

    OVPN

    OVPN¶

    Officiële website

    1. Meld je aan bij www.ovpn.com en zoek het onderstaande menu om WireGuard-configuratiebestanden te verkrijgen.

    2. Klik op Generate WireGuard keys, kies de gewenste server en download de configuratie.

    3. Open de configuratie in een teksteditor en kopieer de inhoud.

      De configuratie kan een IPv6-adres bevatten. Open het .conf-bestand en verwijder het IPv6-adres om compatibiliteits- en verbindingsproblemen te voorkomen. De gemarkeerde inhoud hieronder is de IPv6-inhoud.

    4. Volg daarna deze handleiding om door te gaan.

    5. Je kunt OVPN ook met de mobiele app instellen.

    PrivateVPN

    PrivateVPN¶

    Officiële website

    1. Meld je aan en open het Control panel.

    2. Selecteer een server.

    3. Klik op GENERATE CONFIG en kopieer vervolgens de configuratie.

    4. Volg daarna deze handleiding om door te gaan.

    PrivadoVPN

    PrivadoVPN¶

    Officiële website

    Ga naar de PrivadoVPN-website en meld je aan.

    Zoek in het dashboard het gedeelte Manual Configuration en klik op WireGuard. Selecteer de server waarmee je verbinding wilt maken en klik op Download Configuration.

    Volg daarna deze handleiding om door te gaan.

    Proton VPN

    Proton VPN¶

    Als je Proton VPN gebruikt, volg je de handleiding hier om het WireGuard-configuratiebestand te genereren.

    Volg daarna deze handleiding om door te gaan.

    PureVPN

    PureVPN¶

    Officiële website

    Raadpleeg deze handleiding of volg de onderstaande stappen om het PureVPN-configuratiebestand handmatig te verkrijgen.

    1. Meld je met je account aan bij de PureVPN Member Area. Klik na het aanmelden in het linkermenu op Manual Configuration.

    2. Selecteer de gewenste plaats en klik rechts op Download.

    3. Selecteer in het pop-upvenster WireGuard als protocol.

    4. Selecteer Linux als apparaattype en klik op Generate Configuration. Het configuratiebestand wordt naar je lokale apparaat gedownload.

      Opmerking: de WireGuard-configuratie verloopt na 30 minuten. Activeer de verbinding binnen de geldigheidsduur. Anders moet je een nieuwe configuratie genereren.

    5. Volg daarna deze handleiding om de configuratie te voltooien.

    Referentie: How to set up PureVPN on GL.iNet router

    SpiderVPN

    SpiderVPN¶

    Officiële website

    1. Meld je aan bij www.spidervpn.org en zoek het gedeelte voor je VPN-configuratie. Volg de stappen om de configuratie te verkrijgen.

    2. Download de VPN-configuratie.

    3. Volg daarna deze handleiding om door te gaan.

    StarVPN

    StarVPN¶

    Officiële website

    1. Een account bij StarVPN registreren

      Ga naar de beschikbare abonnementen en kies een VPN-abonnement dat bij je behoeften past. Je kunt je bij het afrekenen of rechtstreeks hier registreren.

    2. De WireGuard-configuratie downloaden

      Meld je aan bij het dashboard voor StarVPN-leden. Klik op WireGuard Config om het configuratiebestand te downloaden. Elke sleuf bevat een uniek WireGuard-configuratiebestand.

      Tips: als je AmneziaWG-obfuscatietechnieken wilt gebruiken, klik je op AmneziaWG Config om het configuratiebestand te downloaden. Elke sleuf bevat een uniek AmneziaWG-configuratiebestand.

    3. Het configuratiebestand bewerken (optioneel)

      De configuratie kan een IPv6-adres bevatten. Open het .conf-bestand en verwijder het IPv6-adres zoals hieronder om compatibiliteits- en verbindingsproblemen te voorkomen.

    4. Volg daarna deze handleiding om het configuratiebestand naar je GL.iNet-router te uploaden.

    Referenties:

    • WireGuard VPN Setup with StarVPN on GL.iNet Router
    • AmneziaWG VPN Setup with StarVPN

    TRUST.ZONE

    TRUST.ZONE¶

    Officiële website

    VPN.AC

    VPN.AC¶

    Officiële website

    1. Als je VPN.AC gebruikt, meld je je aan bij het configuratiescherm en zoek je WireGuard Manager in het menu "Services".

    2. Maak de configuratie en download deze.

    3. Volg daarna deze handleiding om door te gaan.

    VPN Safe

    VPN Safe¶

    Officiële website

    1. Meld je aan bij het VPN Safe Dashboard en klik op je actieve VPN-dienst.

    2. Scrol in de productdetails omlaag naar WireGuard Configuration.

    3. Er zijn twee manieren om VPN Safe WireGuard-configuraties te downloaden, afhankelijk van het aantal configuraties dat je nodig hebt:

      • Als je één configuratie wilt downloaden, selecteer je de gewenste server in de vervolgkeuzelijst en klik je op Download Config. Je kunt ook de QR-code rechts met de WireGuard-app scannen om snel verbinding te maken.

      • Als je alle configuraties wilt downloaden, klik je op Download All om een ZIP-bestand te krijgen. Pak het uit om alle beschikbare configuratiebestanden te verkrijgen.

    4. Volg daarna deze handleiding om verder te gaan.

    Referentie: How to Add a VPN Safe WireGuard Config to a GL.iNet Router

    VPN Unlimited(KeepSolid)

    VPN Unlimited(KeepSolid)¶

    Officiële website

    1. Als je VPN Unlimited gebruikt, meld je je aan bij je User Office > selecteer je de toepassing VPN Unlimited® > en klik je op Manage.

    2. Klik op het veld onder Device en klik op Manually create a new device… > voer een aangepaste naam in, bijvoorbeeld WireGuard > kies de gewenste locatie bij Server > selecteer het protocol WireGuard® in de vervolgkeuzelijst > en klik op Generate.

    3. De configuratieparameters worden vervolgens hieronder in tekstindeling weergegeven.

      Combineer de configuratie als volgt.

      [Interface]
      PrivateKey = plak de PrivateKey uit je User Office
      ListenPort = plak de ListenPort-gegevens
      Address = plak de Address-informatie
      DNS = plak de DNS-gegevens uit de User Office

      [Peer]
      PublicKey = plak de PublicKey uit de User Office
      PresharedKey = plak de PresharedKey-gegevens
      AllowedIPs = plak de AllowedIPs-gegevens
      Endpoint = plak de Endpoint-informatie

    4. Volg daarna deze handleiding om door te gaan.

    Referentie: How to Configure WireGuard Client on GLiNet Router

    X-VPN

    X-VPN¶

    Officiële website

    X-VPN is vanaf firmware v4.11 geïntegreerd in GL.iNet-routers.

    Als je router firmware v4.11 of nieuwer gebruikt, kun je je met een aanmeldingstoken rechtstreeks in het GL.iNet-webbeheerpaneel aanmelden bij X-VPN. Klik hier voor meer informatie.

    Volg de onderstaande stappen als je router firmware ouder dan v4.11 gebruikt of als je handmatig een X-VPN-configuratiebestand wilt downloaden.

    1. Meld je aan bij X-VPN en ga naar VPN -> VPN on Router.

    2. Zoek rechts Step 1 en selecteer WireGuard als protocol.

    3. Kies bij Step 2 de gewenste Region en State/City en klik op Search.

    4. Klik in de zoekresultaten op de downloadknop om het configuratiebestand voor de gewenste server op te halen.

    Volg daarna deze handleiding om door te gaan.
